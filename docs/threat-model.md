# Threat Model

## Assets

- 目的と非目的の正確な共有。
- 事実と根拠の対応。
- 公開判断に必要な承認境界。
- 正本と生成物の一致。
- AIへ渡す文脈の完全性。

## Threats

### Prompt injection

外部文書が命令文を含み、AIがプロジェクト指示として採用する。対策は信頼区分、引用隔離、優先順位契約、警告検査です。

### Context omission

トークン予算のために結論の前提や制約が欠落する。対策は固定アンカーと依存閉包です。

### Stale truth

外部仕様や数値が古いまま有効ブロックに残る。対策は揮発フラグ、失効日、公開前ゲートです。

### Metric gaming

キーワード反復や文章水増しで「意味スコア」が上がる。対策は単一スコアを持たず、構造ゲートとタスクベンチマークを分けることです。

### Generated artifact drift

READMEだけが手編集され、正本と異なる。対策は自己ホスト再生成とGit差分検査です。

### Broken provenance

コピーされた主張の所有者や根拠が失われる。対策は安定ID、更新日、根拠辺、意味スナップショットです。

## Residual risk

語彙ベース検索は、暗黙的な言い換えや専門語の対応を見落とす可能性があります。命令注入の文字列検査も完全ではありません。これらはベンチマーク拡張と、利用側の権限・安全規則によって補完します。
