コメント「リードミー生成器って意味なくね？なにそれ？」に答えます。

「生成器」という名前が分かりにくかったです。正確には：

**README を「正しく伝わる構造データ」として管理し、人間にも AI にも取り違えが起きないようにするツール**

## 何が嬉しいか（具体例）

| 状況 | 従来 | これあり |
|---|---|---|
| リリース前確認 | 全文を AI に食わせて迷子 | 必要ブロックだけ渡して確実 |
| 新メンバー | 長い README を全部読ませる | 目的・禁止・次手だけ取り出す |
| README 更新 | 根拠が分からず怖い | 参照・根拠・未確認情報を自動検証 |

## つまり

「長い文章を頑張って書く」のではなく、「意味の部品を管理して、人と AI が取り違えないようにする」ためのツールです。

PR 本文と START_HERE にも同じ具体例表を入れました。スマホで見やすい形式にしています。
